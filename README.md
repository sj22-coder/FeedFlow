# 🌊 FeedFlow

> **Your interests. Your feed. Your flow.**

FeedFlow is an AI-powered personalized content platform designed to deliver a smarter and more relevant content experience. Instead of showing every user the same generic feed, FeedFlow adapts to individual interests and preferences to surface content that matters to them.

## 📁 Project Resources

- 🎥 **Project Demo:** https://drive.google.com/file/d/190ojqk2xcH1KmtyiBexrxJI5XtXDFif7/view?usp=sharing

## ✨ Key Features

- 🤖 **AI-Powered Personalization**  
  Personalizes the content experience based on the user's interests and preferences.

- 🎯 **Interest-Based Feed**  
  Users can select topics such as AI, Technology, Startups, Business, Finance, Gaming, Travel, Fitness, Health, and Education.

- 📰 **Personalized Content Discovery**  
  Helps users discover relevant content without having to search through unrelated information.

- 🔄 **Dynamic Feed Experience**  
  The feed is designed to evolve as user preferences change.

- 📱 **Cross-Platform Mobile Application**  
  Built using React Native and Expo for a modern mobile experience.

- 🎨 **Clean & User-Friendly UI**  
  Simple navigation and an interface designed around content discovery.
